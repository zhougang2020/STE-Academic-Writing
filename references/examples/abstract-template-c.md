# Abstract Template C (Multiple Contributions)

## Skeleton

1. [Task sentence]
2. [Optional: contrast with prior methods]
3. We propose [contribution 1], which [advantage 1].
4. We also introduce [contribution 2], which [advantage 2].
5. [Optional: contribution 3 + advantage 3]
6. Experiments show [main result].

## Notes

When there are multiple technical contributions, describe each contribution together with its technical advantage in one sentence. This ability is critical for writing a good abstract.
